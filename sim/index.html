Geometry and estimates

A model for learning. χ³ is exaggerated for teaching. Real Kerr index changes are around Δn ≈ 10⁻⁸ to 10⁻⁶.

What is computed?

Maxwell’s equations in 2D for light with its electric field perpendicular to the image plane (TM, Ez only). For this polarization, they reduce exactly to a scalar wave equation: ∂²D/∂t² = ∇²E with D = εE + χ³·N·E.

  • Kerr effect: N = E² (instantaneous), or N follows E² with response time τ (Debye). Fundamental-frequency approximation: Δε ≈ ¾χ³A² for the instantaneous model. The approximation ≈ ½χ³A² applies only to slow Debye response (ωτ ≫ 1). Otherwise, the real part is c(τ)χ³A² with c(τ) = ½ + 1/[4(1+(2ωτ)²)]; a quadrature component also appears. Δt/τ ≤ 1 is checked.
  • Grid: isotropic 9-point Laplacian, leapfrog time step Δt = 0.5 cells/c. Boundary: sponge/absorbing layer (shown dark).
  • Sources inject the computed fundamental mode consistently with the stencil. Probes sum smoothed E² along a line: a proxy for relative intensity. The spectrum uses one cell per probe. The ratio approximates power transmission only for identical linear single-mode ports with small reflections. Direction and energy flux are not measured.
  • Limits: χ³ is exaggerated by orders of magnitude to make effects visible within a few hundred wavelengths. Real Kerr index changes are around Δn ≈ 10⁻⁸…10⁻⁶, requiring resonators with a high quality factor Q. The 2D model omits the chip height: a real device requires a 3D calculation.
